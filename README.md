This project is a frontend travel agency web application that features an interactive booking form and real-time price calculation using JavaScript. It allows users to simulate travel bookings while dynamically updating costs based on selected options.

The application focuses on delivering a smooth user experience through responsive design, form validation, and efficient client-side logic.

---

🚀 Features

- 🌍 Select travel destinations dynamically
- 📝 Interactive booking form with validation
- 💰 Real-time price calculation using JavaScript
- 📱 Fully responsive design for mobile and desktop
- 🎨 Clean and user-friendly interface

---

🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Responsive Design)
- JavaScript (DOM Manipulation, Events)
